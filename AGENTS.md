# Portfolio contributors

Read [docs/DESIGN.md](docs/DESIGN.md) before changing a project, its presentation, or portfolio copy. It contains the Living Showcase design intent, Forma reference, verified JadeWords feature boundaries, and the visual acceptance checklist.

Keep project content in the typed `src/projects.ts` layer. Real product claims require implementation or supplied evidence; placeholder concepts remain clearly fictional.

For a visual change, compare the actual rendered project with Forma on desktop and mobile, in Browse, Immerse and the technical section. Unit tests alone do not establish visual quality. Verify keyboard focus, Escape/exit, navigation history, reduced motion and missing media as applicable, then run the repository's lint, tests and production build.

Use the existing stack and approved local assets. Keep new assets small. Preserve `.git`, unrelated work and product-source repositories. Do not deploy, merge or push without current authorization for that action.
